# Scratch Implementation of Neural Networks

This repository contains from-scratch implementations of:
- Artificial Neural Network (ANN)
- Convolutional Neural Network (CNN)
- Recurrent Neural Network (RNN)

## Constraints
- Implemented without using deep learning libraries
- Only NumPy and standard Python libraries used

## Structure
- ann/: Feedforward neural network with backpropagation
- cnn/: Convolution, pooling, and fully connected layers
- rnn/: Vanilla RNN with Backpropagation Through Time

## How to Run
Each folder contains a standalone implementation.
